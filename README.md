# Clock-UI

A simple clock, alarm, stopwatch, and timer built with Vite.

## Run locally

```sh
npm install
npm run dev
```

## Deploy to GitHub Pages

Every push to `main` builds the project and deploys it to:

<https://amartorells-esliceu.github.io/Clock-UI/>

The repository's Pages source must be set to **GitHub Actions** in its
**Settings → Pages** configuration.
